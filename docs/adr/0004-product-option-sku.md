# ADR-0004: 상품 옵션 = SKU (사이즈 단축, 색상은 별도 상품)

- **상태**: 채택(Accepted)
- **근거**: [architecture.md §11](../architecture.md) · [dev-log](../dev-log.md)

## 배경 (Context)
패션 커머스라 한 상품에 사이즈/색상 변형이 있다. 재고·가격을 변형 단위로 관리해야 하지만, 옵션 축을 늘릴수록 모델·UI·재고 매트릭스가 복잡해진다. 패션 셀렉트샵 도메인 모델에 맞는 단순화가 필요했다.

## 결정 (Decision)
옵션 축을 **사이즈 단일 축**으로 단축하고, **색상은 별도 상품**으로 분리하는 셀렉트샵 모델을 택한다. 재고와 `@Version` 낙관적 락을 `Product`에서 **`ProductOption`(=SKU)** 으로 이동하고, `Product.stock` 컬럼은 제거했다. 주문/장바구니는 `optionId` 기준으로 식별한다(같은 상품 다른 사이즈는 별개 항목). 장바구니/주문 컷오버 후 죽은 stock/version 컬럼은 런타임 검증으로 발견해 DROP.

## 대안 (Alternatives)
- **(A) 다축 옵션(사이즈 × 색상 매트릭스)** — 모델·재고·UI 복잡도 폭증, 학습 단계에 과함 → 탈락.
- **(B) 옵션 없이 상품 = 재고단위** — 사이즈 변형 표현 불가 → 탈락.

## 결과 (Consequences)
- **긍정**: 재고/동시성 제어가 SKU(옵션) 단위로 정확, 모델 단순.
- **부정**: 색상이 별도 상품이라 카탈로그에 동일 디자인이 여러 상품으로 노출됨(셀렉트샵에선 수용 가능). 시드 옵션이 대부분 FREE라 사이즈 필터 시연이 제한적.
