# ADR-0001: Spring Boot 3.5.14 고정 (4.0 회피)

- **상태**: 채택(Accepted)
- **근거**: [dev-log](../dev-log.md) · [CLAUDE.md](../../CLAUDE.md)

## 배경 (Context)
신규 학습/포트폴리오 프로젝트라 안정성과 풍부한 레퍼런스가 중요했다. 초기 세팅 1일차에 Initializr에서 Boot 4.0을 실수로 설치한 적이 있다. .NET에서 백엔드로 전환하는 학습 곡선상, 최신 메이저(4.0)의 깨지는 변경·자료 부족을 감당할 여유가 없었다.

## 결정 (Decision)
Spring Boot를 **3.5.14로 고정(pin)** 한다. Java 21 toolchain, Gradle Wrapper. 4.0은 의도적으로 금지하고, 스택 변경 시 사용자 확인을 필수로 둔다. 1일차에 4.0 실수 설치를 발견해 3.5.14로 재생성했다.

## 대안 (Alternatives)
- **(A) Boot 4.0 최신** — 자료 부족·깨지는 변경으로 학습 비용↑ → 탈락.
- **(B) 더 낮은 2.x LTS** — Jakarta EE 네임스페이스 등 현행 실무와 괴리, 신규 학습 가치↓ → 탈락.
- 미래 마이그레이션이 필요하면 메이저를 단계적으로 경유하기로.

## 결과 (Consequences)
- **긍정**: 안정적이고 자료가 풍부한 기반에서 패턴 학습에 집중. CLAUDE.md·memory에 영속화해 재발 방지.
- **부정**: 4.0 신규 기능은 못 씀, 추후 메이저 업그레이드 시 단계 경유 비용 발생.
